期权结构解读

  1. 做市商仍是加速器，但加速力度减弱：Gamma＝期权仓位对价格变化的敏感度；净做市商 GEX（GEX＝做市商净 Gamma 暴露，白话：判断对冲是减震还是加速的指标）双模型同步收窄——FlashAlpha 11/18 为 -18.3M（前值 -20.8M）、SquawkFlow 11/19 为 -$10.5M（前值 -$11.9M），两家方向一致仍为负。负 Gamma＝加速器：做市商追涨杀跌、放大波动；正 Gamma＝减震器：涨了卖、跌了买，波动被压缩。
  2. 现价夹在两道墙之间，下方地板已收敛、上方天花板接近收敛：Put Wall＝期权仓位堆出的下跌地板，Call Wall＝上涨时的天花板。11/19 收盘 $68.65 位于已收敛的 gamma Put 墙 $65 上方 +5.6%，但已跌破 OI Put 墙 $70（-2.0%）；上方 gamma Call 墙 $73–75，距离 -6.3% 至 -9.3%。
  3. 墙位被破之后，地板和天花板都会变成加速器：若 $65 被跌破，Put 墙地板转为向下的加速器（做市商随跌势卖出）；若站上 $73–75，Call 墙阻力转为向上的加速器。
  4. Max Pain 不是目标价：Max Pain $85（全部到期日口径）是静态均衡点（Max Pain＝期权到期时价格最容易被吸向的位置），较现价 +23.8%——它是均衡点、不是目标价，不要把它当上涨目标。
  5. 成交异动不支持突破，更多是震荡收敛：最热行权价仍为 $70，但全链成交量/OI（成交量除以未平仓量，白话：当天交易热度相对存量仓位）降至 0.35（前值 0.40）、OI Rank 升至 68（前值 62），更多是震荡收敛而非突破信号。IV Rank（白话：期权贵不贵的排名，IV Rank 高＝期权贵、市场在为大波动付钱）52/100 中等，30 日 ATM IV 70.3%，期权仍在为大波动付钱。

事实 / 推断 / 情景分开看——已核实事实：11/19 收盘价 $68.65；各模型墙位与 GEX 符号（FlashAlpha -18.3M、SquawkFlow -$10.5M 均为负；gamma Put 墙两家同为 $65 已收敛，OI Put 墙 $70）；OI 数据（看涨 1,175,033 / 看跌 803,788）。模型推断：做市商对冲方向为假设、非可观测事实——负 Gamma 体制下对冲会追涨杀跌、放大波动，是模型推断而非已发生的事实。风险情景：跌破 $65 后地板转为向下加速器的情景，与站上 $73–75 后阻力转为向上加速器的情景，均为情景、非预测。

这对持股人意味着什么：负 Gamma 加速器体制下波动会被放大而非被吸收，但双模型同步收窄说明加速力度在减弱；现价已跌破 OI Put 墙 $70、仍守在 gamma Put 墙 $65 上方。该盯的两个价位：下方盯 $65（gamma Put 墙），上方盯 $73–75（gamma Call 墙）。
