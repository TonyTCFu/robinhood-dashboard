期权结构解读

  1. 负 Gamma 体制：波动会被放大，不是被压缩：净做市商 GEX 已翻负（−1.5M），做市商从“减震器”变“加速器”——股价涨他们追买、跌他们追卖。进入 10/27 财报前，这意味着任何方向的推动都容易超调，别按上周正 Gamma 时的“跌多了会自己稳住”来预期。
  2. 现价贴在地板边缘，上方 5% 是三重簇：10/23 收盘 $95.07 仅高于 gamma Put 墙 $95 不足 0.1%；上方 $100（+5.2%）同时是 gamma Call 墙、Max Pain 与 OI Put 墙三重位；OI Call 墙 $120 远在 +26.2%，短期无关。$95–$100 就是财报前的战场区间。
  3. 墙破会怎样：跌破 $95，脚下的地板变成加速区——做市商顺势卖出对冲，下行会自我强化；站上 $100，头顶的阻力簇反而变上行助燃剂（空头回补 + 做市商买入对冲）。在负 Gamma 下，两边的突破都比平时走得更远。
  4. Max Pain 不是目标价：$100 是全部到期日口径的静态均衡点（价格容易被吸向它，但它不是任何人的目标价）；10/27 财报后这个均衡点会被重新定价。
  5. 成交异动支持“重仓对峙”：最热行权价已下移到 $100，全链成交量/OI 0.49，OI Rank 86/100（31 天偏重区）——$95–$100 区间堆了大量仓位。钉价（价格被吸在墙位附近）与突破两种力量都在，财报是裁决点；负 Gamma 体制下，一旦裁决出方向，跟随走势的概率高于均值回归。
  6. 已核实 / 模型推断 / 风险场景：已核实——墙位（OptiView OI 口径 $120/$100；FlashAlpha gamma 口径 $100/$95）、Max Pain（$100，全部到期日口径）、IV / IV Rank、成交比、GEX 符号与数值（−1.5M，10/21 为 +36.2M），均为 10/22 OPRA / OCC 快照；模型推断——负 Gamma 放大波动、$95/$100 得失决定财报前节奏；风险场景——墙位为 10/22 快照，财报前会重画，DOJ 指控（10/23 盘后披露）等事件冲击不在这张快照里，别当定论。

这对持股人意味着什么：财报前是“加速器”体制：现价贴着 $95 地板线，上方 $100 是三重阻力簇，任何一边破位都容易走出超调行情，仓位管理要按放大后的波动（期权隐含 ±15.8%）来想，而不是按平常日子。该盯的两个价位：$95（gamma Put 墙，跌破打开做市商加速下行区）、$100（gamma Call 墙 + Max Pain + OI Put 墙三重簇，阻力）。
